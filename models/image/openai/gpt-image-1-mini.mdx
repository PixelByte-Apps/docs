Generate images from text descriptions with OpenAI's affordable GPT Image 1 Mini model. Supports text-to-image generation and image editing.

| Property | Value |
|----------|-------|
| **Provider** | OpenAI |
| **Model** | GPT Image 1 Mini |
| **Capability** | Text to Image |
| **Base Cost** | 11,000 micro-cents/request ($0.011) |
| **Processing Time** | ~30 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="openai/gpt-image-1-mini/text-to-image">
  Model slug. Use `openai/gpt-image-1-mini/text-to-image` for text-to-image generation.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for text-to-image generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Text description of the image to generate. Max length: 5,000 characters.
    </ParamField>
    <ParamField body="aspect_ratio" type="string">
      Output aspect ratio. Default: `1:1`. Options: `1:1`, `3:2`, `2:3`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 11,000 micro-cents per request ($0.011)

<Tip>
**Fixed cost:** 11,000 micro-cents ($0.011) per request. No dynamic pricing factors.
</Tip>

## Response

<ResponseField name="jobId" type="string">
  Unique identifier for the submitted job.
</ResponseField>

<ResponseField name="status" type="string">
  Initial job status. Always `"pending"` on successful submission.
</ResponseField>

<ResponseField name="estimatedCompletionTime" type="string">
  ISO 8601 timestamp of the estimated completion time.
</ResponseField>

<ResponseField name="costMicroCents" type="number">
  The cost of the job in micro-cents.
</ResponseField>

## Code Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.muvi.video/v1/jobs/submit \
  -H "Authorization: Bearer $PIXELBYTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-image-1-mini/text-to-image",
    "input": {
      "prompt": "A futuristic cityscape at sunset with flying cars",
      "aspect_ratio": "3:2"
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.muvi.video/v1/jobs/submit",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={
        "model": "openai/gpt-image-1-mini/text-to-image",
        "input": {
            "prompt": "A futuristic cityscape at sunset with flying cars",
            "aspect_ratio": "3:2"
        }
    }
)

data = response.json()
print(data)
```

```javascript JavaScript
const response = await fetch("https://api.muvi.video/v1/jobs/submit", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "openai/gpt-image-1-mini/text-to-image",
    input: {
      prompt: "A futuristic cityscape at sunset with flying cars",
      aspect_ratio: "3:2"
    }
  })
});

const data = await response.json();
console.log(data);
```

## Edit Image

Edit and transform existing images using OpenAI's GPT Image 1 Mini model. Provide a reference image along with a text prompt to guide the editing process.

| Property | Value |
|----------|-------|
| **Provider** | OpenAI |
| **Model** | GPT Image 1 Mini |
| **Capability** | Edit Image |
| **Category** | Image to Image |
| **Base Cost** | 11,000 micro-cents/request ($0.011) |
| **Processing Time** | ~30 seconds |

### Request Body

<ParamField body="model" type="string" required placeholder="openai/gpt-image-1-mini/edit-image">
  Model slug. Use `openai/gpt-image-1-mini/edit-image` for image editing.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for image editing.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Text description for editing the image. Max length: 5,000 characters.
    </ParamField>
    <ParamField body="image_url" type="string">
      Reference image URL for editing. Provide a single image URL to be edited.
    </ParamField>
    <ParamField body="aspect_ratio" type="string">
      Output aspect ratio. Default: `1:1`. Options: `1:1`, `3:2`, `2:3`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

### Pricing

**Base cost:** 11,000 micro-cents per request ($0.011)

<Tip>
**Fixed cost:** 11,000 micro-cents ($0.011) per request. No dynamic pricing factors.
</Tip>
