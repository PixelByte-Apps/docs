Edit images with high-fidelity facial feature preservation using ByteDance+ Seedream V4.5. Supports up to 10 reference images, eight aspect ratios, and resolutions up to 4K.

| Property | Value |
|----------|-------|
| **Provider** | ByteDance+ |
| **Model** | Seedream V4.5 |
| **Capability** | Image to Image / Edit |
| **Base Cost** | 40,000 micro-cents/request ($0.04) |
| **Processing Time** | ~60 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="bytedance-plus/seedream-v4.5/image-to-image">
  Model slug. Use `bytedance-plus/seedream-v4.5/image-to-image`.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for image editing.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Edit instruction describing the desired changes (max 5000 characters).
    </ParamField>
    <ParamField body="image_urls" type="array" required>
      Array of reference image URLs (max 10 images).
    </ParamField>
    <ParamField body="aspect_ratio" type="string" required>
      Output aspect ratio. Default: `1:1`. Options: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `21:9`.
    </ParamField>
    <ParamField body="resolution" type="string" required>
      Output resolution. Default: `2k`. Options: `512p`, `1k`, `2k`, `4k`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 40,000 micro-cents per request ($0.04)

```
finalCost = baseCost × resolution
```

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Resolution** | `512p` | 1x |
| | `1k` | 1x |
| | `2k` | 1x |
| | `4k` | 1x |

<Tip>
**Default cost:** any resolution = 40,000 × 1 = **40,000 micro-cents ($0.04)**
</Tip>
