title: "Seedream V5 Lite — Text to Image"

---

Generate high-quality images from text prompts using ByteDance+ Seedream V5 Lite, featuring Chain-of-Thought reasoning and up to 4K output. Supports batch generation of up to 4 images per request.

| Property | Value |
|----------|-------|
| **Provider** | ByteDance+ |
| **Model** | Seedream V5 Lite |
| **Capability** | Text to Image |
| **Base Cost** | 35,000 micro-cents/image ($0.035/image) |
| **Processing Time** | ~60 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="bytedance-plus/seedream-v5-lite/text-to-image">
  Model slug. Use `bytedance-plus/seedream-v5-lite/text-to-image`.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for text-to-image generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Text description of the image to generate (max 5000 characters).
    </ParamField>
    <ParamField body="resolution" type="string">
      Output resolution. Default: `2K`. Options: `1K`, `2K`, `4K`.
    </ParamField>
    <ParamField body="aspect_ratio" type="string">
      Output aspect ratio. Default: `1:1`. Options: `1:1`, `16:9`, `9:16`, `3:2`, `2:3`, `4:3`, `3:4`.
    </ParamField>
    <ParamField body="num_images" type="string">
      Number of images to generate per request. Default: `1`. Options: `1`, `2`, `3`, `4`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 35,000 micro-cents per image ($0.035/image)

```
finalCost = baseCost × num_images
```

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Number of Images** | `1` | 1x |
| | `2` | 2x |
| | `3` | 3x |
| | `4` | 4x |

<Tip>
**Default cost:** 1 image = 35,000 × 1 = **35,000 micro-cents ($0.035)**
</Tip>

## Response

<ResponseField name="jobId" type="string">

<ResponseField name="status" type="string">

<ResponseField name="costMicroCents" type="number">

</ResponseField>

```bash cURL
curl -X POST https://api.muvi.video/v1/jobs/submit \
  -H "Authorization: Bearer $PIXELBYTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "bytedance-plus/seedream-v5-lite/text-to-image",
```

```python Python

    "https://api.muvi.video/v1/jobs/submit",

        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={

        "input": {
            "prompt": "An ultra-detailed 4K product shot of a glass perfume bottle on marble"
        }
    }
)

data = response.json()
print(data)
```
