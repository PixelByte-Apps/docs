Edit and transform existing images at professional quality with PixelByte+'s Pixel Image 1.0 Pro model. Provide one or more reference images along with an edit instruction to guide the transformation.

| Property | Value |
|----------|-------|
| **Provider** | PixelByte+ |
| **Model** | Pixel Image 1.0 Pro |
| **Capability** | Image to Image / Edit |
| **Category** | Image to Image |
| **Base Cost** | 45,000 micro-cents/image ($0.045) |
| **Processing Time** | ~30 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="pixelbyte-plus/pixel-image-1.0-pro/image-to-image">
  Model slug. Use `pixelbyte-plus/pixel-image-1.0-pro/image-to-image` for image editing.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for image editing.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Edit instruction describing the desired transformation. Max length: 5,000 characters.
    </ParamField>
    <ParamField body="image_urls" type="array" required>
      List of input image URLs to edit. Provide between 1 and 4 URLs.
    </ParamField>
    <ParamField body="size" type="string">
      Output resolution tier. Default: `2K`. Options: `1K`, `2K`.
    </ParamField>
    <ParamField body="num_images" type="string">
      Number of images to generate per request. Default: `1`. Options: `1`, `2`, `3`, `4`. Affects pricing.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 45,000 micro-cents per image ($0.045)

```
finalCost = baseCost × num_images
```

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Number of Images** | `1` | 1x |
| | `2` | 2x |
| | `3` | 3x |
| | `4` | 4x |

<Tip>
**Default cost:** 1 image = 45,000 × 1 = **45,000 micro-cents ($0.045)**

**4-image cost:** 45,000 × 4 = **180,000 micro-cents ($0.180)**
</Tip>
