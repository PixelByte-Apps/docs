Generate a smooth video that transitions from a start frame to an end frame with Kling I2V Frames V2.5. Ideal for controlled keyframe animation, morphing transitions, and product shots.

| Property | Value |
|----------|-------|
| **Provider** | Kling |
| **Model** | Kling I2V Frames V2.5 |
| **Capability** | Start-End Frame to Video |
| **Base Cost** | 50,000 micro-cents/second ($0.05/sec) |
| **Processing Time** | ~240 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="kling/kling-i2v-frames-v25/start-end-frame-to-video">
  Model slug. Use `kling/kling-i2v-frames-v25/start-end-frame-to-video`.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for start-end frame video generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string">
      Text description guiding the transition (max 2500 characters).
    </ParamField>
    <ParamField body="image_url" type="string" required>
      URL of the start frame image.
    </ParamField>
    <ParamField body="end_image_url" type="string" required>
      URL of the end frame image.
    </ParamField>
    <ParamField body="quality" type="string">
      Generation quality. Default: `std`. Options: `std`, `pro`.
    </ParamField>
    <ParamField body="duration" type="string">
      Video duration in seconds. Default: `5`. Options: `5`, `10`.
    </ParamField>
    <ParamField body="aspect_ratio" type="string">
      Video aspect ratio. Default: `16:9`. Options: `16:9`, `9:16`, `1:1`.
    </ParamField>
    <ParamField body="seed" type="integer">
      Optional random seed for reproducible results.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 50,000 micro-cents per second ($0.05/sec)

```
finalCost = baseCost × quality × duration
```

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Quality** | `std` | 1x |
| | `pro` | 1.5x |
| **Duration** | `5` | 5x |
| | `10` | 10x |

<Tip>
**Default cost:** std quality, 5 seconds = 50,000 × 1 × 5 = **250,000 micro-cents ($0.25)**
</Tip>
