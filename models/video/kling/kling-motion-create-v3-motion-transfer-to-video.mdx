---
title: "Kling Motion 3.0 — Motion Transfer to Video"
api: "POST /v1/jobs/submit"
description: "Transfer motion from a reference video onto a still image using Kling Motion 3.0 via PixelByte API"
---

Apply the motion of a reference video onto a still input image with Kling Motion 3.0. The output duration is derived from the motion video, and quality can be tuned via std/pro tiers.

| Property | Value |
|----------|-------|
| **Provider** | Kling |
| **Model** | Kling Motion 3.0 |
| **Capability** | Motion Transfer to Video |
| **Base Cost** | 70,000 micro-cents/second ($0.07/sec) |
| **Processing Time** | ~240 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="kling/kling-motion-create-v3/motion-transfer-to-video">
  Model slug. Use `kling/kling-motion-create-v3/motion-transfer-to-video`.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for motion transfer generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="image_url" type="string" required>
      URL of the input image to animate.
    </ParamField>
    <ParamField body="motion_video_url" type="string" required>
      URL of the reference video that supplies the motion.
    </ParamField>
    <ParamField body="prompt" type="string">
      Optional text description guiding the animation (max 2500 characters).
    </ParamField>
    <ParamField body="quality" type="string">
      Generation quality. Default: `std`. Options: `std`, `pro`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 70,000 micro-cents per second ($0.07/sec)

```
finalCost = baseCost × duration × quality
```

The output duration is derived from the reference motion video.

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Duration** | `5` | 5x |
| | `10` | 10x |
| **Quality** | `std` | 1x |
| | `pro` | 1.5x |

<Tip>
**Default cost:** 5 seconds, std quality = 70,000 × 5 × 1 = **350,000 micro-cents ($0.35)**
</Tip>

## Code Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.muvi.video/v1/jobs/submit \
  -H "Authorization: Bearer $PIXELBYTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling/kling-motion-create-v3/motion-transfer-to-video",
    "input": {
      "image_url": "https://example.com/image.jpg",
      "motion_video_url": "https://example.com/motion.mp4",
      "prompt": "Match the dance motion smoothly",
      "quality": "std"
    }
  }'
```
