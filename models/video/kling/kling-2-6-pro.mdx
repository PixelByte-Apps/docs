Generate high-quality videos with Kling 2.6 Pro. Supports text-to-video and image-to-video capabilities with optional audio generation.

| Property | Value |
|----------|-------|
| **Provider** | Kling |
| **Model** | Kling 2.6 Pro |
| **Capabilities** | Text to Video, Image to Video |
| **Base Cost** | 70,000 micro-cents/second ($0.07/sec) |
| **Processing Time** | ~240 seconds |

## Model Slugs

| Capability | Slug |
|------------|------|
| Text to Video | `kling/kling-2.6-pro/text-to-video` |
| Image to Video | `kling/kling-2.6-pro/image-to-video` |

## Request Body

<ParamField body="model" type="string" required placeholder="kling/kling-2.6-pro/text-to-video">
  Model slug. Use one of the slugs listed above based on the desired capability.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for video generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Text description of the video to generate (max 2500 characters).
    </ParamField>
    <ParamField body="image_url" type="string">
      URL of the input image. **Required** for `image-to-video`.
    </ParamField>
    <ParamField body="aspect_ratio" type="string">
      Video aspect ratio. Default: `16:9`. Options: `16:9`, `9:16`.
    </ParamField>
    <ParamField body="duration" type="string">
      Video duration in seconds. Default: `5`. Options: `5`, `10`.
    </ParamField>
    <ParamField body="has_sound" type="string">
      Enable audio generation. Default: `false`. Options: `true`, `false`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 70,000 micro-cents per second ($0.07/sec)

```
finalCost = baseCost × duration × has_sound
```

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Duration** | `5` | 5x |
| | `10` | 10x |
| **Sound** | `false` | 1x |
| | `true` | 2x |

<Tip>
**Default cost:** 5 seconds, no sound = 70,000 × 5 × 1 = **350,000 micro-cents ($0.35)**
</Tip>
