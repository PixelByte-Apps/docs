---

Generate videos from images with Kling 2.6 I2V. This model specializes in image-to-video generation with built-in audio (always on).

| Property | Value |
|----------|-------|
| **Provider** | Kling |
| **Model** | Kling 2.6 I2V |
| **Capability** | Image to Video |
| **Base Cost** | 40,000 micro-cents/second ($0.04/sec) |
| **Processing Time** | ~240 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="kling/kling-2.6-i2v/image-to-video">
  Model slug. Use `kling/kling-2.6-i2v/image-to-video` for image-to-video generation.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for image-to-video generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Text description of the video to generate (max 2500 characters).
    </ParamField>
    <ParamField body="image_url" type="string" required>
      URL of the input image to animate.
    </ParamField>
    <ParamField body="duration" type="string">
      Video duration in seconds. Default: `5`. Options: `5`, `10`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 40,000 micro-cents per second ($0.04/sec)

```
finalCost = baseCost × duration
```

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Duration** | `5` | 5x |
| | `10` | 10x |

<Tip>
**Default cost:** 5 seconds = 40,000 × 5 = **200,000 micro-cents ($0.20)**
</Tip>

## Response

<ResponseField name="jobId" type="string">
  Unique identifier for the submitted job.
</ResponseField>

<ResponseField name="status" type="string">
  Initial job status. Always `"pending"` on successful submission.
</ResponseField>

<ResponseField name="estimatedCompletionTime" type="string">
  ISO 8601 timestamp of the estimated completion time.
</ResponseField>

<ResponseField name="costMicroCents" type="number">
  The cost of the job in micro-cents.
</ResponseField>

## Code Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.muvi.video/v1/jobs/submit \
  -H "Authorization: Bearer $PIXELBYTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling/kling-2.6-i2v/image-to-video",
    "input": {
      "prompt": "A golden retriever running through a sunlit meadow",
      "image_url": "https://example.com/dog.jpg",
      "duration": "5"
    }
  }'
```

```python Python

        "input": {

            "image_url": "https://example.com/dog.jpg",
            "duration": "5"

)

data = response.json()
print(data)
```
