---
title: "Kling O1 — Text to Video"
api: "POST /v1/jobs/submit"
description: "Generate videos from text prompts using Kling O1 via PixelByte API"
---

Generate videos from a text prompt with Kling O1. Supports std/pro quality tiers, 16:9/9:16/1:1 aspect ratios, and 5- or 10-second durations.

| Property | Value |
|----------|-------|
| **Provider** | Kling |
| **Model** | Kling O1 |
| **Capability** | Text to Video |
| **Base Cost** | 70,000 micro-cents/second ($0.07/sec) |
| **Processing Time** | ~240 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="kling/kling-omni-o1/text-to-video">
  Model slug. Use `kling/kling-omni-o1/text-to-video`.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for text-to-video generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Text description of the video to generate (max 2500 characters).
    </ParamField>
    <ParamField body="quality" type="string">
      Generation quality. Default: `std`. Options: `std`, `pro`.
    </ParamField>
    <ParamField body="duration" type="string">
      Video duration in seconds. Default: `5`. Options: `5`, `10`.
    </ParamField>
    <ParamField body="aspect_ratio" type="string">
      Video aspect ratio. Default: `16:9`. Options: `16:9`, `9:16`, `1:1`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 70,000 micro-cents per second ($0.07/sec)

```
finalCost = baseCost × duration × quality
```

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Duration** | `5` | 5x |
| | `10` | 10x |
| **Quality** | `std` | 1x |
| | `pro` | 1.5x |

<Tip>
**Default cost:** 5 seconds, std quality = 70,000 × 5 × 1 = **350,000 micro-cents ($0.35)**
</Tip>

## Response

<ResponseField name="jobId" type="string">
  Unique identifier for the submitted job.
</ResponseField>

<ResponseField name="status" type="string">
  Initial job status. Always `"pending"` on successful submission.
</ResponseField>

<ResponseField name="estimatedCompletionTime" type="string">
  ISO 8601 timestamp of the estimated completion time.
</ResponseField>

<ResponseField name="costMicroCents" type="number">
  The cost of the job in micro-cents.
</ResponseField>

## Code Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.muvi.video/v1/jobs/submit \
  -H "Authorization: Bearer $PIXELBYTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling/kling-omni-o1/text-to-video",
    "input": {
      "prompt": "A futuristic city skyline at dusk with neon lights",
      "quality": "std",
      "duration": "5",
      "aspect_ratio": "16:9"
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.muvi.video/v1/jobs/submit",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={
        "model": "kling/kling-omni-o1/text-to-video",
        "input": {
            "prompt": "A futuristic city skyline at dusk with neon lights",
            "quality": "std",
            "duration": "5",
            "aspect_ratio": "16:9"
        }
    }
)

data = response.json()
print(data)
```
