title: "Kling 2.5 Turbo Pro — Text to Video"

---

Generate high-quality videos from text descriptions with Kling 2.5 Turbo Pro. Supports multiple aspect ratios, durations, and prompt-guidance controls.

| Property | Value |
|----------|-------|
| **Provider** | Kling Plus |
| **Model** | Kling 2.5 Turbo Pro |
| **Capability** | Text to Video |
| **Base Cost** | 50,000 micro-cents/second ($0.05/second) |
| **Processing Time** | ~240 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="kling-plus/kling-2.5-turbo-pro/text-to-video">
  Model slug. Use `kling-plus/kling-2.5-turbo-pro/text-to-video` for text to video generation.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for text to video generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Text description of the video to generate. max 2500 characters.
    </ParamField>
    <ParamField body="aspect_ratio" type="string">
      Video aspect ratio. Options: `16:9`, `9:16`, `1:1`. Default: `16:9`.
    </ParamField>
    <ParamField body="duration" type="string">
      Video duration in seconds. Options: `5`, `10`. Default: `5`.
    </ParamField>
    <ParamField body="guidance_scale" type="number">
      Prompt adherence strength. min 0, max 1. Default: `0.5`.
    </ParamField>
    <ParamField body="negative_prompt" type="string">
      Negative prompt. max 1000 characters.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 50,000 micro-cents per second ($0.05/second)

```
finalCost = baseCost × duration
```

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Duration** | `5` | 5x |
|  | `10` | 10x |

<Tip>
**Default cost** (duration=`5`): 50,000 × 5 = **250,000 micro-cents ($0.25)**
</Tip>

## Response

<ResponseField name="jobId" type="string">
  Unique identifier for the submitted job.
</ResponseField>

<ResponseField name="status" type="string">
  Initial job status. Always `"pending"` on successful submission.
</ResponseField>

<ResponseField name="estimatedCompletionTime" type="string">
  ISO 8601 timestamp of the estimated completion time.
</ResponseField>

<ResponseField name="costMicroCents" type="number">
  The cost of the job in micro-cents.
</ResponseField>

## Code Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.muvi.video/v1/jobs/submit \
  -H "Authorization: Bearer $PIXELBYTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-plus/kling-2.5-turbo-pro/text-to-video",
    "input": {
      "prompt": "A golden retriever running through a sunlit meadow during sunrise, cinematic camera motion.",
      "aspect_ratio": "16:9",
      "duration": "5"
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.muvi.video/v1/jobs/submit",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={
        "model": "kling-plus/kling-2.5-turbo-pro/text-to-video",
        "input": {
            "prompt": "A golden retriever running through a sunlit meadow during sunrise, cinematic camera motion.",
            "aspect_ratio": "16:9",
            "duration": "5"
        }
    }
)

data = response.json()
print(data)
```
