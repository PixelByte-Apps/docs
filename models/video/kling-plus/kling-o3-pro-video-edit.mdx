Edit an existing video using a natural-language instruction with the Kling O3 Pro model.

| Property | Value |
|----------|-------|
| **Provider** | Kling Plus |
| **Model** | Kling O3 Pro |
| **Capability** | Video Edit |
| **Base Cost** | 50,000 micro-cents/second ($0.050/sec) |
| **Processing Time** | ~180 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="kling-plus/kling-o3-pro/video-edit">
  Model slug. Use `kling-plus/kling-o3-pro/video-edit` for video edit generation.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for video edit generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Text prompt describing the desired output (max 2500 characters).
    </ParamField>
    <ParamField body="video_url" type="string" required>
      Video URL (max 10s).
    </ParamField>
    <ParamField body="images" type="array">
      Reference images (max 4).
    </ParamField>
    <ParamField body="keep_original_sound" type="boolean">
      Keep the audio track from the source video. Default: `true`.
    </ParamField>
    <ParamField body="shot_type" type="string">
      Shot composition mode. Default: `customize`. Options: `customize`, `intelligent`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 50,000 micro-cents per second ($0.050/sec)

```
finalCost = baseCost (flat per-video)
```

<Tip>
**Cost:** flat **50,000 micro-cents ($0.050)** per video.
</Tip>

## Response

<ResponseField name="jobId" type="string">
  Unique identifier for the submitted job.
</ResponseField>

<ResponseField name="status" type="string">
  Initial job status. Always `"pending"` on successful submission.
</ResponseField>

<ResponseField name="estimatedCompletionTime" type="string">
  ISO 8601 timestamp of the estimated completion time.
</ResponseField>

<ResponseField name="costMicroCents" type="number">
  The cost of the job in micro-cents.
</ResponseField>

## Code Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.muvi.video/v1/jobs/submit \
  -H "Authorization: Bearer $PIXELBYTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-plus/kling-o3-pro/video-edit",
    "input": {
      "prompt": "Replace the background sky with a vibrant sunset and add a flock of birds",
      "video_url": "https://example.com/video.mp4"
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.muvi.video/v1/jobs/submit",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={
        "model": "kling-plus/kling-o3-pro/video-edit",
        "input": {
            "prompt": "Replace the background sky with a vibrant sunset and add a flock of birds",
            "video_url": "https://example.com/video.mp4"
        }
    }
)

data = response.json()
print(data)
```
