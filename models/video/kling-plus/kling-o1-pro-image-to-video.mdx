---
title: "Kling O1 Pro — Image to Video"
api: "POST /v1/jobs/submit"
description: "Generate videos with the Kling O1 Pro model using image to video."
---

Animate a still image into a high-quality video with the Kling O1 Pro model. Provide an `image_url` and an optional `prompt` to guide motion.

| Property | Value |
|----------|-------|
| **Provider** | Kling Plus |
| **Model** | Kling O1 Pro |
| **Capability** | Image to Video |
| **Base Cost** | 70,000 micro-cents/second ($0.070/sec) |
| **Processing Time** | ~240 seconds |

## Request Body

<ParamField body="model" type="string" required placeholder="kling-plus/kling-o1-pro/image-to-video">
  Model slug. Use `kling-plus/kling-o1-pro/image-to-video` for image to video generation.
</ParamField>

<ParamField body="input" type="object" required>
  Input parameters for image to video generation.
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string">
      Text prompt describing the desired output (max 2500 characters).
    </ParamField>
    <ParamField body="image_url" type="string" required>
      URL of the input image.
    </ParamField>
    <ParamField body="duration" type="string">
      Video duration in seconds. Default: `5`. Options: `3`, `4`, `5`, `6`, `7`, `8`, `9`, `10`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="webhookUrl" type="string">
  HTTPS URL to receive a webhook notification when the job completes or fails.
</ParamField>

## Pricing

**Base cost:** 70,000 micro-cents per second ($0.070/sec)

```
finalCost = baseCost × duration
```

| Factor | Option | Multiplier |
|--------|--------|-----------|
| **Duration** | `3` | 3x |
|  | `4` | 4x |
|  | `5` | 5x |
|  | `6` | 6x |
|  | `7` | 7x |
|  | `8` | 8x |
|  | `9` | 9x |
|  | `10` | 10x |

<Tip>
**Default cost:** 5 seconds = 70,000 × 5 = **350,000 micro-cents ($0.350)**
</Tip>

## Code Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.muvi.video/v1/jobs/submit \
  -H "Authorization: Bearer $PIXELBYTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-plus/kling-o1-pro/image-to-video",
    "input": {
      "prompt": "The astronaut slowly turns toward the camera as cosmic dust drifts past",
      "image_url": "https://example.com/image.jpg",
      "duration": "5"
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.muvi.video/v1/jobs/submit",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={
        "model": "kling-plus/kling-o1-pro/image-to-video",
        "input": {
            "prompt": "The astronaut slowly turns toward the camera as cosmic dust drifts past",
            "image_url": "https://example.com/image.jpg",
            "duration": "5"
        }
    }
)

data = response.json()
print(data)
```
